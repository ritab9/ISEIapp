Student Status Definitions
Enrolled Currently enrolled and attending the school.
Part Time Currently enrolled but attending on a part-time basis.
Accepted Accepted for enrollment but has not yet begun attending. Change to Enrolled once the student begins attending.
Withdrawn Attended during the current school year but subsequently left the school. A Withdraw Date is required.
Did Not Return Completed the previous school year but did not return for the current school year. Use this at the beginning of the new school year rather than Withdrawn.
Graduated Completed the school's graduation requirements and graduated.
No Show Expected or registered to attend but never actually began attending during the school year.
Bulk Actions
Accepted → Enrolled Changes all students currently marked Accepted to Enrolled. Use only after confirming that those students have actually begun attending.
Registration Date Apply adds the selected date only where the registration date is blank. Rewrite replaces existing registration dates, so use it only when intentionally changing them.
Location & Boarding These controls apply the selected value to all student records currently displayed in the form.
  • Please review all student records carefully before submitting the report. Check enrollment status, grade level, registration date, address, baptismal status, boarding status, and other information for accuracy.
  • The report remains active throughout the school year: “Report Complete” does not lock the report. Update it whenever students withdraw or new students enroll so that it always reflects the school's current enrollment. At the end of the school year, the report must reflect the school's actual closing enrollment.
